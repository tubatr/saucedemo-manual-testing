# BUG-001: Product information mismatch between listing and detail pages

**Environment:** SauceDemo – Web Application  
**Test Account:** `problem_user`

**Preconditions:**
- User is logged in with `problem_user`.
- Products page is displayed.

**Steps to Reproduce:**
1. Log in using `problem_user` and `secret_sauce`.
2. Open the Products page.
3. Observe the product names, images and prices.
4. Click on any product.
5. Compare the information on the product detail page with the product listing page.
6. Repeat the steps with other products.

**Expected Result:**
The product detail page should display the same product name, image, price and description as the selected product on the Products page.

**Actual Result:**
The product detail page displays information that does not match the selected product on the Products page. Product names, images, prices and descriptions are inconsistent across all products.

**Severity:** To be assessed  
**Priority:** High 
**Status:** High

The issue occurs with all products when using problem_user.
The same issue could not be reproduced using standard_user.
Product information was consistent on both the listing and detail pages.
